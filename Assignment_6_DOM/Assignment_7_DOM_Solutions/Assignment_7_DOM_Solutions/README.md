# Assignment 7 – DOM JavaScript Solutions

This submission contains nine independent mini-projects. Each question has its own `index.html`, `style.css`, and `script.js`.

## How to run
1. Extract the ZIP file.
2. Open the folder for the question you want to test.
3. Open its `index.html` in a browser (or use VS Code Live Server).
4. Open the browser Developer Tools Console if you want to inspect runtime messages.

## Questions
1. Dynamic Product List Manager (event delegation, inline editing, outside-click auto-save)
2. Live Character Counter (100-character limit, warning colors, reset)
3. Multi-Step Form (name, email, password validation, back/next, summary)
4. Theme Switcher (Light, Dark, Blue using `setAttribute()`)
5. Image Gallery (modal preview, outside-click close, `stopPropagation()`)
6. Real-Time Student Table Filter (case-insensitive)
7. Mouse Coordinates Logger (400×400 area, double-click red markers)
8. Custom Dropdown (no `<select>`, outside-click close in capturing phase)
9. Form Submit Blocker (inline validation, `preventDefault()`, live error clearing)

All solutions use core JavaScript without frameworks.
